🌐 2. গ্লোবাল স্ট্যান্ডার্ড ও প্রটোকল

2.1 Base URL & Routing

  • লোকাল ডেভেলপমেন্ট: http://127.0.0.1:8000 বা http://localhost:8000
  • API V1 প্রিফিক্স: /api/v1 (বেশিরভাগ বিজনেস রুট /api/v1/smartflow/... এর অধীনে)
  • পাবলিক ওয়েব রুট: /api/v1/public/... এবং /legal/..., /content/...
  • রুটিন হেলথ রুট: /health, /healthz, /ready

2.2 Authentication & Token Flow

সিস্টেমে স্টেটলেস JWT (JSON Web Token) বিয়ারার অথেনটিকেশন ব্যবহৃত হয়: 1. লগইন রিকোয়েস্ট: POST /api/v1/auth/login (email + password) রিটার্ন করে access_token এবং refresh_token। 2. অথরাইজেশন হেডার: প্রতিটি সুরক্ষিত রুটে অবশ্যই নিচের হেডার পাঠাতে হবে: http Authorization: Bearer <access_token> 3. টোকেন রোটেশন: Access Token-এর মেয়াদ ৩০ মিনিট। এক্সপায়ার হলে POST /api/v1/auth/refresh-token কল করে নতুন এক্সেস টোকেন পাওয়া যায়। 4. রোল হায়ারার্কি ও RBAC: owner > supervisor > staff > user। ব্যাকএন্ডের require_permission(module, action) ডিপেন্ডেন্সি প্রতিটি রিকোয়েস্টে পারমিশন চেক করে।

2.3 রেট লিমিটিং পলিসি (Rate Limiting)

রুট টাইপ লিমিট উইন্ডো মেথডোলজি হেডার্স
Auth Endpoints (/api/v1/auth/*) ২০ রিকোয়েস্ট ৬০ সেকেন্ড ক্লায়েন্ট আইপি ভিত্তিক স্লাইডিং উইন্ডো Retry-After, X-Request-ID
Mutation Endpoints (POST/PUT/PATCH/DELETE) ১২০ রিকোয়েস্ট ৬০ সেকেন্ড আইপি ভিত্তিক স্লাইডিং উইন্ডো (Redis / In-memory) Retry-After, X-Request-ID
Safe GET Queries আনলিমিটেড (সাধারণ) — মেমরি সুরক্ষিত X-Request-ID

2.4 স্ট্যান্ডার্ড রেসপন্স এনভেলপ (Response Envelope)

ব্যাকএন্ডের প্রতিটি API সুসংগত ও স্ট্যান্ডার্ড JSON কাঠামো রিটার্ন করে:

সফল রেসপন্স (Success 200/201):

{
  "success": true,
  "message": "Resource fetched successfully.",
  "data": {
    "id": "69efae8b5af39608a990e09e",
    "name": "Example Data"
  }
}

ব্যর্থ রেসপন্স (Error 4xx/5xx):

{
  "success": false,
  "message": "Human-readable error explanation.",
  "error": {
    "code": "VALIDATION_ERROR | PERMISSION_DENIED | NOT_FOUND",
    "details": {
      "field": "email is required"
    }
  }
}

2.5 রিয়েল-টাইম WebSockets গাইড

ব্যাকএন্ডে ৩টি প্রধান WebSocket রুট সক্রিয় রয়েছে: 1. GET /api/v1/calls/stream/{call_id}: Telnyx থেকে ইনকামিং কলের লাইভ অডিও ফোর্ক স্ট্রিমিং (G.711 mu-law অডিও বাফার)। 2. GET /api/v1/smartflow/ws/conversations/{conversation_id}?token={jwt}: নির্দিষ্ট কাস্টমার চ্যাট থ্রেডের লাইভ মেসেজ স্ট্রিমিং ও টাইপিং ইন্ডিকেটর। 3. GET /api/v1/smartflow/ws/inbox?token={jwt}: পুরো অর্গানাইজেশনের ইউনিফাইড ইনবক্স নোটিফিকেশন হাব (নতুন SMS, WhatsApp মেসেজ আসার নোটিফিকেশন)।
